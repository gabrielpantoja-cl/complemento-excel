# Skill: Indemnización por Servidumbre Eléctrica (SEC)

Calcula la indemnización conforme a LGSE DFL 4/20.018, DS 113, y DS 52, aplicando las 6 categorías de daño y el recargo legal del 20%.

## Prerequisite

- Appraisal report with the affected property data
- Base land value (valor base del suelo) already computed
- Physical measurements: tower footprint areas, easement strip dimensions, construction areas affected

## The 6 categories

| # | Category | Methodology |
|---|---|---|
| 1 | Land occupied by physical works (bases de torres) | Full land value × affected area |
| 2 | Transit right compensation (derecho de tránsito) | % of land value × easement strip area |
| 3 | Easement strip with use restrictions (franja de servidumbre) | Depreciation % × land value × strip area |
| 4 | Damage to structures (daños a construcciones) | Replacement cost of affected structures |
| 5 | Loss of remaining land value (plusvalía del resto) | Before/After method applied to the remainder |
| 6 | Statutory surcharge (recargo legal) | 20% of sum of categories 1–5 |

> **Prohibited:** do not include future value uplift generated by the electrical project itself.

## Workflow

### Step 1 — Read property and project data

Ask the user for:
- `valor_suelo_uf_m2` — base land unit value (UF/m²)
- `area_bases_torres_m2` — total footprint of tower bases (m²)
- `ancho_franja_m` — easement strip width (m)
- `largo_franja_m` — easement strip length (m)
- `area_construcciones_afectadas_m2` — affected construction area (m²)
- `valor_construcciones_uf_m2` — replacement cost of constructions (UF/m²)
- `porcentaje_restric_franja` — restriction factor for easement strip (% depreciation, typically 15–40%)
- `porcentaje_derecho_transito` — transit right factor (typically 5–15% of land value)
- `valor_antes_uf` — total property value before easement
- `valor_despues_uf` — total property value after easement (for Before/After)

Mark all input cells with style "input" (yellow fill).

### Step 2 — Calculate each category

```
# Category 1: Tower footprints (full expropriation)
cat_1 = valor_suelo_uf_m2 × area_bases_torres_m2

# Category 2: Transit rights
area_franja_m2 = ancho_franja_m × largo_franja_m
cat_2 = valor_suelo_uf_m2 × area_franja_m2 × porcentaje_derecho_transito

# Category 3: Use restrictions on easement strip
cat_3 = valor_suelo_uf_m2 × area_franja_m2 × porcentaje_restric_franja

# Category 4: Construction damage
cat_4 = valor_construcciones_uf_m2 × area_construcciones_afectadas_m2

# Category 5: Remaining land value loss (Before/After)
cat_5 = max(0, valor_antes_uf - cat_1 - valor_despues_uf)

# Category 6: Statutory surcharge
subtotal = cat_1 + cat_2 + cat_3 + cat_4 + cat_5
cat_6 = subtotal × 0.20

total_indemnizacion = subtotal + cat_6
```

### Step 3 — Write indemnization table

Write a table named `INDEMNIZACION_SEC` with:

| Category | Description | Area / Factor | UF/m² | Subtotal UF | CLP |
|---|---|---|---|---|---|
| 1 | Suelo ocupado por obras físicas | | | | |
| 2 | Derecho de tránsito | | | | |
| 3 | Franja de servidumbre (uso restringido) | | | | |
| 4 | Daños a construcciones | | | | |
| 5 | Pérdida de plusvalía del resto | | | | |
| — | **Subtotal** | | | | |
| 6 | Recargo legal 20% | | | | |
| — | **TOTAL INDEMNIZACIÓN** | | | | |

Apply `style: "total-row"` to subtotal and total rows. Format UF as `#.##0,00` and CLP as `$ #.##0`.

### Step 4 — Verify

- Confirm category 5 does not include project-generated value uplift.
- Confirm recargo is exactly 20% of categories 1–5.
- Confirm CLP conversion uses the input UF cell (not a hardcoded value).

## Output

Table `INDEMNIZACION_SEC` with all 6 categories, subtotal, 20% surcharge, and total — in UF and CLP.
