Tus reglas

Formatos chilenos por defecto

El separador de miles con punto (1.331.832), decimales con coma (33,54), fechas en formato DD-MM-AAAA. Valores en UF y CLP con el formato que usa el SII y los tribunales chilenos.

Puedes definir tus propias convenciones y skills especializadas. El sistema de reglas persistentes recuerda tus preferencias para cada libro y cada tipo de tasación.

Instalación
Tres pasos, sin herramientas de desarrollo

Descarga un archivo, cópialo en una carpeta y abre Excel. Si usas un agente como Claude Code, puedes pedirle que haga todo esto por ti.

1 Descarga el manifest

Este pequeño archivo le dice a Excel dónde encontrar Tasaciones. Es lo único que necesitas descargar.

manifest.prod.xml

2 Cópialo a la carpeta de add-ins de Excel

Abre Terminal y pega esto. Crea la carpeta si es necesario y copia el archivo.

$ mkdir -p ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef && \
  cp ~/Downloads/manifest.prod.xml ~/Library/Containers/com.microsoft.Excel/Data/Documents/wef/
¿Lo guardaste en otra carpeta? Cambia ~/Downloads/ por la ruta donde lo tengas.

3 Abre Tasaciones en Excel

  1. Sal de Excel completamente (⌘Q) y vuelve a abrirlo
  2. Ve a Insert → Mis complementos
  3. Haz clic en Tasaciones para abrir la barra lateral
Importante — Tasaciones se basa en Pi for Excel, construido y probado en macOS. Debería funcionar en Windows pero no ha sido probado extensivamente. Si tienes problemas, abre un issue en GitHub.

1 Descarga el manifest

El mismo archivo de configuración que le dice a Excel dónde encontrar Tasaciones.

manifest.prod.xml

2 Súbelo en Excel

  1. Abre Excel
  2. Ve a Insert → Mis complementos → Subir complemento…
  3. Selecciona el archivo manifest.prod.xml que descargaste
Importante: usa Subir complemento… para este archivo — no uses Administrar → XML Expansion Packs. Esa ruta antigua puede mostrar errores de certificado engañosos.

3 Abre la barra lateral

Haz clic en Abrir Tasaciones en la cinta de opciones.

Funciona con OpenRouter, Anthropic, OpenAI, Google, GitHub y cualquier proveedor compatible con API OpenAI.

OpenRouter (recomendado) Recomendado

OpenRouter te da acceso a decenas de modelos con una sola API key. Modelos gratuitos incluidos (50 req/día). Con USD $10 en crédito subes a 1000 req/día gratis + modelos de paga. Solo pagas los tokens que usas.

Modelos disponibles:

  • openrouter/free — router automático de modelos gratuitos
  • google/gemini-2.5-flash — bueno y económico
  • openai/gpt-4o-mini — sólido y rápido
  • anthropic/claude-sonnet-4.6 — el mejor para análisis
BYOK (Bring Your Own Key): Consigue tu API key en openrouter.ai/keys, pégala en /settings del complemento y empieza a usar.

API key directa Simple

Si ya tienes API key de Anthropic, OpenAI o Google, pégala directamente. Sin proxy, sin configuraciones adicionales. En la barra lateral, escribe /login, expande tu proveedor, pega tu key y guarda.
